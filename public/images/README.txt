PNG EXPRESS - VISION SHOWCASE IMAGES
======================================

Place your 3 Vision Showcase photos in this exact folder:
D:\transport_system\Transport_System_Soliution\public\images\

File names to use:
------------------
1. First Card (Left):
   vision-1.jpg  (or vision-1.png / vision-1.jpeg / vision-1.webp)
   Theme: Express Fleet (Exterior of bus, on highway, etc.)

2. Second Card (Center):
   vision-2.jpg  (or vision-2.png / vision-2.jpeg / vision-2.webp)
   Theme: Cabin Interior (Reclining seats, passenger comfort, etc.)

3. Third Card (Right):
   vision-3.jpg  (or vision-3.png / vision-3.jpeg / vision-3.webp)
   Theme: Safety & Operations (Dashboard, GPS telematics, driver, etc.)

Recommended Image Size:
-----------------------
- Aspect Ratio: 4:3 or 16:9
- Resolution: ~800 x 600 px (or any standard phone/camera photo)
